# Real game assets for the Roundtable Hold

Export low-poly meshes from The Last Blood (UE5: right-click asset -> Asset Actions
-> Export -> .gltf/.glb, or via Blender) and drop them here:

- knight.glb  -> replaces the procedural knight you control.
                 If the file contains animations, the first clip auto-plays.
                 Any size works - it is auto-scaled to ~1.75 units tall.
- statue.glb  -> decorative statue placed beside the bonfire (auto-scaled ~3.2 tall).

Keep them light (< 2-5 MB, ideally < 10k triangles) for fast loading.
Missing files are fine - the hub falls back to procedural meshes.
