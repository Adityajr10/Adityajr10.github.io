# Project media folder

Drop your media here — filenames are referenced in `js/data.js` for this project.

- cover.jpg      -> card thumbnail (16:10)
- photos/*.jpg   -> gallery stills (shown in the modal)
- videos/*.mp4   -> full demo clip(s), controls in modal
- shorts/*.mp4   -> 0.4-0.6s micro-clips, autoplay + loop (hover + modal)

Anything missing degrades to a styled placeholder. See ../../ADD_A_PROJECT.md.
